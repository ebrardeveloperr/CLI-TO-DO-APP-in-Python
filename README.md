CLI To-Do App

A simple command-line To-Do application developed in Python as a Week 1 learning project. The application allows users to create, view, complete, and delete tasks directly from the terminal.





Features

\- Add new tasks

\- View all available tasks

\- Mark tasks as completed

\- Delete tasks

\- Display task status

\- Input validation for task operations

\- Interactive command-line menu








Technologies Used



\- Python 3

\- Lists

\- Dictionaries

\- Functions

\- Loops

\- Conditional statements

\- Exception handling

\- enumerate()

How to Run

1\. Clone the repository

git clone https://github.com/ebrardeveloperr/CLI-TO-DO-APP-in-Python



2\. Navigate to the project directory

cd CLI-To-Do-App



3\. Run the application

python todo.py



Usage

After running the application, the following menu will be displayed:

1\. Add Task

2\. View Tasks

3\. Mark Task as Completed

4\. Delete Task

5\. Exit



Enter the corresponding number to perform an operation.
